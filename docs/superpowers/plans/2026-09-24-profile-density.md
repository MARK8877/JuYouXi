# 我的页面紧凑化实施计划

## 目标与边界

减少“我的”页面头部、快捷操作、播放历史和菜单之间的纵向占位；保留现有数据来源、入口文案语义、路由和未开放功能反馈。不改其它页面、接口、数据库或依赖。

## 设计约束

- 延用已确认线框中的炭灰/暖石头色头部、浅灰页面底色、白色内容卡和珊瑚色会员按钮。
- 缩小头部头像与历史剧封面，收紧卡片内外间距；区块间隔由 16dp 收到 8dp。
- 快捷入口和菜单的可点区域仍不小于 48dp；历史标题和“更多”保持现有含义及动作。
- 使用现有 Material 图标、主题和组件，不增加依赖或拆分文件。
