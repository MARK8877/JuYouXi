# 视频详情沉浸页设计

## 目标

从视频首页底部的“免费观看”入口进入后，仍使用与视频首页相同的沉浸式播放器样式；当前短剧的每一集作为垂直分页内容，上下滑动切换并自动循环播放当前集。

## 交互

- 首页短剧卡片点击后直接 push 到沉浸式详情页，默认定位第 1 集并自动播放；详情页返回回到首页。
- 入口页和详情页都复用顶部返回/搜剧/资料、右侧点赞/评论/收藏/分享、底部短剧信息与播放控制。
- 详情页 `PageView` 的每一页对应一个 `Episode`；激活页建立播放会话，离开页释放播放器和播放会话。
- 详情页底部“免费观看”入口打开选集底部弹窗，不再跳转到传统详情列表。
- 选集弹窗使用三列九宫格，每个单元格至少 48dp 高；当前集使用填充色和勾选图标表达，不只依靠颜色。
- 弹窗标题栏右侧提供带语义标签的关闭图标；点击关闭不改变当前集。
- 视频画面下方的海报底图使用轻度高斯模糊和放大裁切，避免竖屏视频两侧出现生硬空白。
- 页面/应用失去播放焦点或打开评论、选集、搜索覆盖层时暂停当前视频；视频暂停后显示中心播放按钮，点击后继续播放。
- 首页及其他 Tab 被选中时不创建视频分页内容；只有视频 Tab 可见时才创建当前播放器，离开视频 Tab 时释放播放器和播放 session。
- 正在播放的视频支持单击暂停；暂停态显示中心播放按钮，点击后恢复播放。

## 边界与可访问性

- 继续复用现有 `LibraryApi` 播放会话和 `_VideoPage` 播放逻辑，不新增后端接口或依赖。
- 保持 SafeArea、至少 44pt 的图标/按钮触控区、Semantics/tooltip 标签和现有深色视频遮罩。
- 预览模式仍使用本地占位集，不发起真实播放请求。
