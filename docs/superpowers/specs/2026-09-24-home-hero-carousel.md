# 首页海报轮播设计

## 已确认线框

```text
┌────────────────────────────┐
│         主海报 1 / 10       │  随机抽取的短剧封面铺满背景
│                            │  底部渐暗，标题与类型/集数
│  [小海报] [小海报]          │  来自同一批短剧，点击进入详情
│             ● ● ● …        │  左右滑动切换，圆点指示当前位置
├────────────────────────────┤
│ 横向分类筛选                │
│ 正在上演                  部数│
│ [封面]      [封面]      [封面]│  首页片库封面不显示 finish 状态角标
└────────────────────────────┘
```

## 范围与行为

- 从成功加载的剧集数据中无重复随机选择最多 10 部；每次载入后选一次，不在普通重建时洗牌。
- 主海报和最多两张小海报均显示实际剧集封面；每张都进入现有短剧详情/第一集路径。
- 主海报可左右滑动；圆点同步显示当前位置并提供可访问的页码说明。
- 搜索入口、品牌标题和项目描述继续保留；分类筛选及“正在上演”网格继续使用现有实现。
- 仅首页网格卡片隐藏 `releaseStatus` 封面角标；搜索结果中的角标及其余剧集元信息不变。
- 演员肖像、独播徽标、锁定图标没有数据/状态依据，不实现。

## 视觉原则与自检

- 色彩由实际海报提供；顶部品牌和底部文字使用克制的深色渐层保证可读性，不叠加无意义装饰。
- 中文剧名作为首要层级，元信息次之；点击区域不少于 48pt，并提供描述性语义标签。
- 保留空封面/加载失败回退，不新增包；在小屏和大字布局下保持可滚动，不遮挡底部 TabBar。
- 自我批评：海报轮播容易沦为占空间的广告位；限制为最多 10 个、提供页码和直接详情入口，且不隐藏原分类与片库。

## 已确认：个人页顶部背景

```text
状态栏渐变 ─┐
             ├─ 连续的深灰 → 暖灰渐变
头像 / 用户信息 / VIP / 设置控件保持原位
```

- 状态栏背景与个人信息头部使用同一条水平渐变，消除两段之间的色差接缝。
- 只改变顶部背景的画法和系统状态栏背景色；头像、用户信息、VIP、设置及页面滚动结构不变。
